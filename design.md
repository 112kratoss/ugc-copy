# UGC Copy Design System Index

Use this file as the first stop for UI and UX work. Open the platform guide that matches the surface you are changing, then use the long research note when you need the reasoning behind the rules.

- [Web UI/UX guide](./design-web.md): Next.js, Tailwind, Geist, Lucide, landing pages, creator workflows, feed/showcase, modals, and web primitives.
- [Mobile UI/UX guide](./design-mobile.md): Expo, React Native, `appTheme`, `components/ui.tsx`, safe areas, tab surfaces, mobile feeds, viewers, and touch controls.
- [Research source](./docs/ui-consistency-research-2026-06-14.md): Pinterest Gestalt, Material 3, Apple HIG, Shopify Polaris, Atlassian, and the current UGC Copy audit.

Shared north star: UGC Copy should feel like a premium dark AI creator studio. The product is media-led, fast to output, and consistent through shared tokens, Lucide icons, strict spacing, stable type roles, and reusable primitives.

Do not duplicate full design rules here. Keep this file as an index so future agents know where to look.
