# ByteDance-family research (2026-08-24)

Primary official sources: Seedance 2.5 guide docs.byteplus.com/en/docs/ModelArk/2607689 · Seedance 2.0-series guide /2222480 · Seedance 1.5 Pro guide /2168087 · Seedream 4.x–5.x guide /1829186 · Seedream 5.0 Pro tutorial /2582774 · interactive editing /2582775.

## seedance-1.5-pro
**Official**: formula **Subject + Movement + Environment (opt) + Camera (opt) + Aesthetic (opt) + Sound (opt)**. Native joint audio-video; CN+EN. Degree adverbs ("first rotates slowly, then stops"); feature-based subject descriptions kept consistent. Dialogue verbatim patterns: `In a calm emotional state, with an even tone and a normal speaking pace, say: "…"`; `He said in Cantonese, "…"`; multi-speaker `English dialogue:` + `Speaker label: "line"` per line; specify speaker gender/age/clothing/position for lip-sync attach. Voiceover: `Generate a video with voiceover: A deep, calm male voice says, "…"`. **BGM generated by default** — control via style/mood words or "no music". Multi-shot via prose cuts ("The scene cuts to…", `Shot 1: … Shot 2: Cut to …`). Camera: "Subject + Shot Size" grammar; movement = "start-frame composition + movement + amplitude + end-frame composition"; vocab dolly-in/out, pan, track, follow, rise, fall, whirl, rotate, surround, zoom; combos allowed (Hitchcock zoom); angles high/low/bird/eye, OTS, POV, fisheye. Legacy `--rs 720p --rt 16:9` suffixes exist on ModelArk — **never emit on Kie**.
**Kie** (bytedance/seedance-1-5-pro): prompt 3–20,000. duration 4–12s. resolution 480p/720p/1080p (default 720p). aspect_ratio 6 options — **default 1:1, always set it**. input_urls 0–2 (2 = first+last, inferred). fixed_lens bool (default false). **generate_audio default FALSE** (costs more on). No negative/seed/watermark.
**Community**: fixed-lens interplay — enable toggle only for locked-off shots, never pair with pan/orbit language; "static tripod shot" stops residual micro-moves; param+prompt agreement critical, redundancy harmless, contradiction = real failure. One camera instruction/shot; fast camera + complex scene + fast subject = chaos.
**Recipe**: (1) subject → movement → environment → camera → style → sound; one scene brief per shot; (2) 2–3 fixed visual features, identical wording every mention; (3) quantify motion (adverbs, body part + range); slow continuous > violent; (4) one camera instruction/shot, start→move→end form; (5) fixed_lens true → add "fixed camera, static shot" + strip movement verbs; user wants movement → fixed_lens false; (6) speech in quotes + speaker desc + delivery; name language if not EN/CN; short lines; one language per clip; (7) dialogue/SFX/BGM only if generate_audio true (defaults OFF on Kie); silence → "no background music"; (8) i2v: describe changes only; (9) externalize emotion as physical behavior; (10) constraints positive: "no subtitles, no logos, no watermark, stable picture, no flicker"; (11) multi-shot 2–5 in 12s, "Shot N:"/"Cut to", never timestamps; (12) 60–200 words; no -- suffixes.

## seedance-2
**Official** (2.0-series guide): advanced formula **"precise subject + action details + scene/environment + lighting & color tone + camera movement + visual style + image quality + constraints"** — "engineering-style instructions, not copywriting". **Reference syntax**: number by upload order; bind explicitly — `Define the woman wearing a red dress and a straw hat in Image 1 as Subject 1` or inline `Zhang San@Image 1`. Task verbs steer routing: omni-reference "Reference <X> in <Video_N>…"; editing "Strictly edit <Video_N>, and modify <A> into <B>" (NEVER "reference Video N" for edits — flips task detection); extension "Extend <Video_N> forward/backward…". State which part of an asset to use ("Refer to Image 1 for lighting and filters"); don't re-describe accurate references. **Shot sequencing**: `Shot 1 / Shot 2 / Shot 3` primary first; **timestamps UNSTABLE on 2.0 — can break generation** (official). Per shot: camera/transition, subject action+expression, spatial change, audio. **Official audio symbol table: Music `（）`, SFX `<>`, Dialogue `{}`, Subtitles/on-screen text `【】`.** One dialogue language; mark uncommon languages. Text-in-video: [Text]+[Timing]+[Position]+[Entrance style],[Color/font]; subtitles "Display subtitles at the bottom-center… synchronized with the audio". Asset strategy: 4 roles — character anchor, scene tone, camera-movement ref, audio atmosphere; **recommended 4–5 assets total**; maxing limits confuses priority. FAQ fixes: ID drift → dedicated headshot + define subject + important assets first + **avoid multi-view sheets on 2.0**; twins → per-character mapping + "Do not generate duplicate characters/twin effect"; >4 ref people unstable → pre-compose group image then i2v; uninvited subtitles → "keep it subtitle-free" + landscape; style drift → explicit style words; voice mismatch → describe timbre ("Use the low, thick, warm… voice of @Audio 1 to say…"); CN polyphonic mispronunciation → homophones.
**Kie** (bytedance/seedance-2): prompt 3–20,000. duration 4–15 (default 5). resolution 480p/720p/1080p/**4k**. aspect 7 opts + adaptive (default 16:9). **generate_audio default TRUE.** reference_image_urls ≤9 (AR 0.4–2.5, 300–6000px), reference_video_urls ≤3 (2–15s each, ≤15s total), reference_audio_urls ≤3. first/last_frame_url — frame modes and reference mode **mutually exclusive**. web_search (t2v only), nsfw_checker. No negative/seed/watermark.
**Community**: fal shot-brief "who, doing what, where, shot how, what it sounds like"; dialogue quoted short + tone; name sounds, "no music" when silence matters (open prompts default to scored content); "cut to"; describe consequences ("leaves scatter on impact"). Timeline/global-context-block pattern: open with 1–3 sentences scene/mood/style for the whole clip. Length: 60–100 vs 30–200 words (mild disagreement); conflicts hurt more than brevity. Physics verbs beat abstractions.
**Recipe**: (1) global style block, then `Shot N:` beats — **never timestamps on 2/fast/mini**; (2) bind every asset by number in upload order (@Image1, Video 1) + purpose + "do not use…" carve-outs; (3) one fixed label per character; anti-twin constraint after casts; (4) one camera instruction/shot, standard vocab; niche terms explained inline; (5) dialogue `{}` (or consistent quotes), music `（）`, SFX `<>`, text `【】`; one language; (6) audio on by default: always specify soundscape; "no BGM"/"no audio" when unwanted; (7) edit verbs only for edit intents; "reference" only for style/motion transfer; (8) quantify actions; 1–2 characters; one shot one verb; (9) negations → supported constraint phrases (subtitles/watermark/logo/duplicates/flicker); (10) short quality tail ("cinematic texture, natural colors, soft lighting, stable picture"); (11) ≤~250 words for ≤15s; (12) i2v: motion/camera/audio changes only.
**Gaps**: bracket-symbol support via Kie untested (model-level, safe).

## seedance-2-fast
**Kie**: identical schema to seedance-2 except resolution **480p/720p only**. generate_audio default true.
**Community**: Mini ≈ or > Fast on coherence/adherence while cheaper (wavespeed, empiriolabs, pixo); Fast's niche thin. Workflow: iterate fast/mini → re-render winner on seedance-2 (prompts transfer verbatim).
**Recipe**: full seedance-2 recipe + trim harder (≤150 words, ≤3 shots); no heavy VFX/crowds; 1–2 characters; no "8K/pore-level" texture promises at 720p; never emit 1080p/4k; keep prompt text portable to seedance-2.

## seedance-2-mini
**Kie**: schema identical to fast: 480p/720p, duration 4–15, refs 9/3/3, generate_audio default true, web_search t2v-only.
**Community**: cheapest tier; "iterate on Mini, finalize on 2.0" standard; Mini reportedly beats Fast on stability. Some hosts list 4/8/12s — Kie documents 4–15, trust Kie.
**Recipe**: same as fast + bias toward a single continuous shot with one camera move (cuts wobble first); ≤4–5 assets (least tolerant of reference overload).

## seedance-2-5
**Official** (richest guide in family, updated 2026-08-13; **ByteDance even ships an official client-side prompt-optimizer skill `sd25-pe` via `npx skills add`** — validation for LLM enhancement): up to 30s, up to 50 reference assets (30 imgs @≤4K, 10 videos ≤30s combined, 10 audio ≤30s combined), 10+ language native generation, editing + extension + transitions. Prompt shape: (1) **one-sentence summary** "Subject + Location + Event + Genre/Style + Camera…", (2) **detailed plot** via timeline or Shot N segments, (3) **additional notes** for recurring constraints. "Use positive descriptions whenever possible. Negative constraints supported ONLY for subtitles and audio" ("no subtitles", "no BGM", "no audio"). **Timestamps NOW WORK** (headline vs 2.0): integer-second ranges `0-3s:` / `[1s-4s]`, point cues ("at the 5-second mark…"), relative cues; gap-free timeline; don't over/under-pack a range; never timestamps for high-frequency actions. References: number by upload order (`Image 1 / Video 1 / Audio 1`; examples use `@Image1`, `[Video 1]`, `<video1>`); "every reference needs a sentence saying what it provides"; don't label characters inside image pixels; mapping lists for casts ("Images 1-2 are Character 1 and correspond to Audio 1…"); accurate ref → "strictly refer to…" instead of re-describing. Sweet spots: **1–8 image subjects (9–12 stretch), 1–5 audio/video subjects, clips 5–10s**; multi-view images OK on 2.5 (unlike 2.0); storyboards ≤15 panels line-art no text; keyframe mode "Use Images 1 to 7 in order as keyframes…". Editing/extension trigger-word driven: "edit video / add / remove / replace / change to", "extend forward/backward / continue"; these lock aspect (must be adaptive) and edits lock duration (-1); prefer mov output. Camera: shot sizes, moves (push in, pull out, pan, track, follow, orbit, dive, pull back, tilt up, handheld shake), angles (low, overhead, FPV), techniques by name (long take, dolly zoom, bullet time, speed ramp); niche terms "[term + plain-language explanation]"; transitions need trigger time + method ("At the 5-second mark, left wipe with a natural dissolve"). Dialogue in 30s examples: `Dialogue (elderly woman): "Fly safe, my child."`; also `[Strictly exclude]` style-exclusion block and `[Subject settings] / [Overall style] / [Shot list]` sectioning. 30s pacing: ~7–10 beats of 2–5s, each = visuals + camera + audio.
**Kie** (bytedance/seedance-2-5): prompt ≤**30,000**. duration 4–30 (default 5; **-1 = auto**). resolution 480p/720p/**1080p** (Kie does NOT expose 4K despite marketing). aspect default **adaptive**. output_format mp4/**mov**. generate_audio default true. refs ≤30 img / ≤10 video (2–30s each, ≤30s total, ≤200MB) / ≤10 audio. first_frame_url/+last. web_search, nsfw_checker. No negative/seed/watermark.
**Community**: tryonr digest restates six-part formula + @image1 bindings + 2.0 symbol set carrying over. Dreamina page: 8-part hierarchy; "write like a director, not a poet"; 30s as 4 macro-beats (00–06 setup / 06–14 action / 14–24 escalation / 24–30 resolution); fight ID drift by naming one primary reference + repeating fixed traits at each major beat. Voice cloning: timbre words + ref pointer.
**Recipe**: (1) duration >10s → gap-free integer-second timeline, one beat per 2–5s; 30s → 7–10 beats; never one unstructured paragraph; (2) summary line → bindings → style → timeline → constraints; (3) every ref one purpose sentence in upload order + "do not use…" carve-outs; casts get mapping list + trait repetition at major beats; (4) edit/extension triggers only on intent — then aspect adaptive (edits duration -1, mov); (5) camera per beat: shot size + one movement + focus target; transitions get timestamp + method; (6) audio every beat: `Dialogue (speaker): "line"` (or {}), SFX <>, music （）; language + accent for non-EN; "No BGM; environmental sounds only" style negatives; (7) negatives ONLY for subtitles/audio + [Strictly exclude] style list; all else positive; (8) timestamps off high-frequency actions; (9) don't restate strict references; fully describe unreferenced subjects; (10) voice refs: @AudioN + verbal timbre; (11) ~100–250 words ≤10s, 300–700 words 30s; (12) prefer duration -1 when beats don't obviously fill fixed length; (13) locked tasks → aspect adaptive, don't fight in text.
**Gaps**: Kie 1080p cap vs native-4K marketing (flag in UI); bracket symbols on 2.5 inherited/asserted — official 2.5 examples use `Dialogue (speaker):` form (safest default).

## seedream-5-pro (image)
**Official**: family rules — coherent natural language "subject + action + environment" + style/color/lighting/composition, NOT keyword soup ("Recommended: A girl in a lavish dress walking under a parasol along a tree-lined path, in the style of a Monet oil painting. Avoid: Girl, umbrella, tree-lined street, oil painting texture."). State application scenario ("Design a logo for… The company name "PITBULL" is written on it"). **Exact text in double quotes.** Editing: concise unambiguous, no vague pronouns, name target + pin what must not change. Multi-image: "Replace the subject in Image 1 with the subject from Image 2", "Dress the character in Image 1 with the outfit from Image 2", "Apply the style of Image 2 to Image 1". Concise precise > ornate. 5.0-pro exclusives: **interactive editing** — sketch/circle marks OR normalized 0–999 coords `<point>x y</point>`, `<bbox>x1 y1 x2 y2</bbox>` (e.g. `Use the subject in Image 2 <bbox>…</bbox> to replace the subject in Image 1 <bbox>…</bbox>`); disambiguate inside a box ("the person on the left"); pin regions "keep the area <bbox>…</bbox> unchanged". Layer decomposition (≤16 alpha layers). **Native multilingual text in 14 extra languages.** **Server-side prompt optimizer: optimize_prompt_options.mode standard (default) | fast — ByteDance rewrites server-side.** Aspect can be stated in natural language. 5.0-pro outputs 1K/1.5K/2K only, one image per request.
**Kie** (seedream/5-pro-*): prompt 3–**5,000**. aspect 8 opts (default 1:1). quality basic (1K) | high (2K). png/jpeg. **image_urls ≤10** on edit endpoint. No seed/negative/watermark. Kie does NOT expose optimize_prompt_options, layer_decomposition, transparent background — coordinate tags still work (prompt-level).
**Community**: Runware — layered prompt **format → subject → composition → lighting → in-image text → style**; soft ceiling **~600 English words**; pin clauses concrete ("Keep the exact silhouette, camera angle, backdrop, and lighting from the reference" — never "keep it the same"); address refs **by content description** ("the tan leather-bound journal") when composing many; white-background packshots lock product identity; omitting format layer defaults to generic portrait photography. Atlas Cloud — realism trick: ask for flaws (sensor noise, handheld softness, "no beauty filters"); two working negation styles: trailing `Negative Prompt: weak expression, distorted hands, watermark` block, or inline "No DSLR look"; garbled text fix = quote + placement; "4K/8K" in prose changes STYLE not pixels; one action per subject. Morphic — SPACE checklist; lighting direction/quality = highest-leverage clause.
**Recipe**: (1) lead with deliverable format + aspect intent; (2) flowing natural language (subject+action+environment+lighting+composition+style) — never comma lists; (3) in-image text quoted + placement + type style; multilingual copy kept verbatim in user's script; (4) realism physics + "no beauty filter, no plastic skin"; (5) edits: one imperative per change, unique target, concrete pin clause; (6) multi-ref: describe by content ("the sneaker from the white-background image") + roles; Image 1/2 indexing works for swaps; (7) pass through <bbox>/<point> tags untouched + noun disambiguators; (8) negations inline or one trailing exclusion list; (9) never "4K/8K" as resolution ask; (10) 80–300 words, hard-stop under 600; (11) don't re-describe references beyond change/keep; (12) server-side optimizer already expands — precise unambiguous clauses; ambiguity, not brevity, is the enemy.
**Gaps**: whether Kie routes i2i to the interactive-edit variant (coordinate tags untested on Kie); Kie caps at 2K.

## seedream-5-lite (image)
**Official**: volume model — batch/sequence output (refs + generated ≤15; trigger "a set of…", "generate four images…", numbered scenes), single/multi editing, streaming; resolution **2K/3K/4K**; no interactive editing/layers (pro-only). All family prompt rules apply. Kie blog: "reasoning, web search, up to 14 references".
**Kie**: 5-lite-text-to-image (prompt 3–**3,000**; quality basic=2K/high=3K/ultra=4K; 8 aspects; png/jpeg) + 5-lite-image-to-image (**image_urls ≤14**; quality tiers slightly inconsistent between endpoints). No seed/negative/watermark. Single image out per task on Kie (batch trigger phrasing may yield grids — unverified).
**Recipe**: (1) Seedream family core rules; (2) 3,000-char cap; 60–250 words; (3) **never emit <bbox>/<point> or layer asks — lite unsupported**; verbal region language or drawn markers on the input image (family-wide); (4) multi-ref edits "Image 1/2" upload order, one mapping sentence each, ≤14, favor ≤5; (5) sets/carousels: enumerate scenes + shared style clause; (6) sketch conversions: "render according to the textual annotations in the sketch"; (7) quoted text + placement; CJK/multilingual keep script; (8) negations inline; (9) quality param controls resolution (lite is the higher-res tier — 4K for typography); (10) surgical edits: verb + unique target + pin clause, no pronouns.
**Gaps**: Kie lite i2i quality-tier labeling inconsistent (verify before UI copy).

## Cross-cutting ByteDance
1. One house style, three generations: "subject + action + environment + camera + style (+ audio) + constraints". 1.5 adds audio-first dialogue; 2.0 adds asset binding + Shot-N + symbol table; 2.5 adds timestamps + task-trigger verbs. Seedream mirrors for stills.
2. **Version-gated syntax is the biggest enhancer trap**: timestamps break 2.0-family but recommended on 2.5; multi-view refs hurt 2.0, OK 2.5; <bbox> tags Seedream-5-PRO-only. Branch on model id.
3. **No negative-prompt field anywhere on Kie.** Negation officially reliable only for subtitles/audio (video) or inline/trailing lists (image). Constraint sentences reduce, not eliminate.
4. **References carry identity; text carries change.** Bind by upload-order number + purpose (+ what to ignore); never re-describe strict refs; never labels inside image pixels; fewer clean refs beat maxed limits (4–5 assets for 2.0; 1–8 subjects 2.5; ≤5 for image edits).
5. **Dialogue always quoted/`{}` with speaker + delivery + language.** Language consistency matters most; CN/EN native, 2.5/Seedream-5 are 10–14-language. **Do not translate user prompts to Chinese** — no evidence of gain; preserve user's script for dialogue and in-image text.
6. **Server-side rewriting differs by line**: Seedream optimizer always on (not exposed by Kie); Seedance has NO rewriter — ByteDance ships the client-side sd25-pe optimizer skill instead (validates Magicbooklet's feature). web_search injects live knowledge (Seedance 2.x t2v, Seedream lite).
7. **Camera vocab is real control**: one move per shot, param/prompt agreement on fixed camera, "[niche term + explanation]". Banned combo: fast camera + fast subject + complex scene.
8. **Length**: hard caps irrelevant (20k/30k/5k/3k); effective ~60–250 words per ≤15s video, 300–700 for 30s, 80–300 (≤600) images. Scale words with shots/beats.
9. **Kie exposes fewer knobs than ModelArk** (no seed/watermark/optimizer mode; 2.5 capped 1080p; Seedream pro capped 2K). Encode aspect/duration/audio as params where Kie has them; never emit --rs/--rt/--cf suffixes.
